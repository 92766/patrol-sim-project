# 基于Web的智能巡检机器人二维仿真系统 (基础版)

## 项目访问方式
直接在浏览器中打开 `index.html` 即可查看界面。（注意：需先在终端运行 `python server.py` 启动后端）

## 项目功能
- **二维地图展示**：基于 Konva.js 绘制，包含空地、障碍物和边界。
- **手动控制**：通过页面上的方向按钮控制机器人移动。
- **碰撞检测**：机器人无法穿越障碍物和地图边界。
- **状态实时反馈**：前端每500ms通过 API 获取机器人最新坐标并刷新。

## 技术栈
- **前端**：HTML5 + Konva.js (通过CDN引入)
- **后端**：Python 3 (原生 `http.server` 库，零依赖)
- **通信**：HTTP RESTful API

## 运行说明
1. 启动后端：在终端执行 `python server.py`
2. 启动前端：直接用浏览器打开 `index.html` 文件。
